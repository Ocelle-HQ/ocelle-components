# Spec check 2

Inputs: `spec.md` (as of 721d74d), `checklists/requirements.md`, `reviews/spec/check-1.md`, `check-1-fixes.md`,
`triage/005-icons-brand-mark.md`, `sources/ocelle-docs-logo.reference.svg`, constitution 1.3.1,
`knowledge/speckit-flows/findings/frontend-missions.md`, and on the branch: `packages/tokens/src/source.ts`,
`packages/tokens/contrast/pairs.json`, `gates/bin/contrast.ts`, `gates/README.md`, `packages/styles/src/base.css`,
`packages/styles/test/pairs.test.ts`, `packages/styles/test/browser/serve.ts`, `packages/elements/package.json`.

Browser probes were run in Chromium 1243 (`OCELLE_CHROMIUM_PATH`), on pages served from 127.0.0.1 with the fixture's
header `default-src 'none'; script-src 'self'; style-src 'self'; font-src 'self'`, and with Playwright's full
accessibility tree (CDP `Accessibility.getFullAXTree`). The results were:

- A module that imports `lit` by a bare specifier does not load. An inline import map is blocked by the CSP, but the
  same page without the CSP loads. An external import map (`<script type="importmap" src>`) does not load even
  without the CSP (SPEC-2-01).
- A `style` attribute in a template that is parsed through `template.innerHTML` and then cloned into a shadow root
  reports one `style-src-attr` violation. So the planted defect in the pairing table works. The cloned style is
  still applied.
- An unlabelled SVG in a shadow root without `aria-hidden` is exposed as an unignored `image ""` node, so that plant
  works too. An SVG with `role="img"` inside a button named by `aria-label` adds an `image` child under the button,
  so the US3-6 plant works.
- A custom-element host that carries an `id` is exposed as an unignored, empty, unnamed `generic` node, even when its
  drawing is `aria-hidden`. Without an `id` the host is ignored. With `ElementInternals.ariaHidden` the host is
  ignored even when it has an `id` (SPEC-2-05).
- In forced colours, an SVG `fill` set from an author colour (`#C68A1E`) is not forced. It keeps the ochre, so FR-027
  needs its own forced-colours rule, and removing that rule is a plant that works.

All four blocking findings of check 1 are resolved as the fix note says. SPEC-1-05 was answered by the operator.
