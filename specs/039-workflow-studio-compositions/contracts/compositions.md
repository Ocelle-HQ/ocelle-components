# Storybook Composition Contracts

## Fixture boundary

The three example mounts expose one fixture root to their respective Storybook files and test harnesses. They use hosted inputs within each fixture and reset independently. User actions enter through existing named elements and native form events. Failing host decisions report an actionable visible state. The example packages no runtime service, new public tag, or dependency.

## Authoring

The semantic comparison includes step identity, reviewer and connections in stable order. The layout and viewport are separate. Listen to the shipped node-selection, viewport, step-position and connection events, capture the exact attempted values before host acceptance, and update only the accepted field. In read-only mode preserve reachable selection and navigation while observing zero workflow mutations following gestures known to reach the intended targets.

The wide inspector is available in the split layout. Narrow activation opens the named drawer and reaches the real reviewer field. Deletion with focus on the removed step reaches the next reachable selected-graph action, Publish decision in the main fixture. When no visible survivor exists, real Step selection or Add step remains a reachable host-owned fallback as appropriate.

## Run inspection

The immutable graph allows selection and viewport only. A real native interview form exposes both single-line and multiline answer values. A refused save presents an accessible error and retains the exact editable text. A successful retry records one event. Present distinct timeline actors, event purposes and evidence, including the later named revision. Return focus to the actual opener once the dialog closes.

## Catalog upgrades

Read the two accepted pins before opening the comparison, while previewing, and after dismissing. Binding adjustments are scoped to the selected instance and stay independent. After the explicit accepted action, the identified instance's displayed digest and version match the offered version. The other digest and both reviewer bindings remain as accepted before. Return focus to the relevant instance after dismissal.

## Published verification

Each story's built index names its executable example. Supply actual browser interactions, pinned theme PNGs, Axe, narrow and representative forced-colour checks. Package-runtime proof uses the same external host and existing strict CSP fixture under HTTP with local resources. Preserve the ordinary package gate.
