# Research decisions for the workflow node

## One native selection control

Use a dedicated native button and the registration and event conventions already used by `ocelle-action-row`. The action-row also supports navigation, host ARIA forwarding, and its own slot and availability semantics. The workflow node needs metadata and an explicit tab-order handoff. Keep its button and descriptive content under one component so the layout has one activation path. Use the card’s ground, spacing and radius token patterns and keep its rule token decorative. Use the repository’s icon conventions wherever a decorative icon is used. [Action row](../../packages/elements/src/ocelle-action-row.ts) · [Card](../../packages/elements/src/ocelle-card.ts) · [Icon](../../packages/elements/src/ocelle-icon.ts)

The default button boundary uses `--ocelle-color-control-border` on the sheet ground. On inset, hover or selected grounds outside that token’s contrast pairings, use the registered `--ocelle-color-accent-strong` pairing for the action boundary and any non-text state cue that needs it. The action uses the token focus ring and `--ocelle-target-min` on both axes from the first public phase. Measure the actual button, and check non-text contrast of at least 3:1 against the adjacent grounds in both themes. Apply the established forced-colors button boundary and focus treatment and retain the text cues. [Token pairings](../../packages/tokens/src/source.ts) · [Shared focus styles](../../packages/elements/src/control.ts)

## Focus and accessible states

Set the native button’s tab participation from a property on the node. Forward `focus()` to that same control after render. The canvas chooses which node stays in sequential order and handles graph navigation. A shadow-local reference provides the button’s full title. Sibling metadata and state text remain readable and supply its description. Use stable text for Selected, Waiting and Invalid so state remains available with equalized colors and to assistive technology. Select a visual focus treatment from the existing focus tokens and prove it in forced colors. [Focus precedents](../../specs/012-button-action-row/)

A generic shadow-button probe in Chromium confirmed native Enter and Space activation, removal and restoration of the button’s tab stop, and direct focus at `-1`. The accessibility tree included the full title and the description from same-root metadata, state text and slotted status. Use a computed accessible description assertion for the component. The generic probe also showed that the accessibility snapshot omitted the description.

Host ARIA needs an explicit handoff to the shadow button. Keep the full title and built-in description in the node’s own root, and combine them with host context through the repository’s host-root lookup and element-reference reflection pattern. Host `aria-current` applies to the button itself and remains independent of the visible selected state. Attribute replacement and removal should refresh the computed name and description and clear stale state without removing built-in information. [Reference reflection precedent](../012-button-action-row/research.md#r-04-id-references-by-element-reflection-engine-floor)

## Host-owned updates

Send one noncancelable, bubbling and composed selection request from the host during the native button’s click handler. Keep native click propagation intact. A graphical host gets the stable ID from the request event and retains responsibility for selection. Read-only inspection uses the identical action. Allow optional noninteractive status content outside the button so a host can provide readable text before the library’s other status elements land. Canvas layout, routing and outcome connections belong to #73. [Node issue](https://github.com/Ocelle-HQ/ocelle-components/issues/72) · [Canvas issue](https://github.com/Ocelle-HQ/ocelle-components/issues/73)

The round-one Chromium probe observed a replacement ID emitted when the same pressed Lit button was rebound between pointer down and release. Replacing the mounted host and button produced no request for the new ID during the interrupted gesture, and a fresh click emitted the new ID once. Key host mounts by step ID so the native action keeps its meaning through title and state updates. [Round-one evidence](reviews/plan/round-1/lens-fresh.yaml)
