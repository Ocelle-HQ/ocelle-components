# Implementation Plan: Grouped copyable identifiers

**Branch**: `035-copy-identifier-groups` | **Specification**: [spec.md](spec.md)

## Approach

Extend `ocelle-copy-field` with Boolean `grouped` and `compact` properties and same-name attributes, both off by default. Compact presentation applies when both options are enabled and the identifier has at least three body groups. Keep raw value and activation-time capture under the existing Copy contract. A different raw value resets the compact presentation. Assigning the same value preserves it.

Keep the existing field and Copy node, name, disablement, status clearing and deferred request. Add one native disclosure button before Copy. Change its visible and accessible name with the available action, and place `aria-expanded` on the actual button. Use a same-shadow-root association if adding `aria-controls`. One activation reveals all groups and the reverse activation returns to compact. Keep the disclosure and Copy node identities stable, with Copy next in Tab order. If a host update removes focused Reveal, move focus to enabled Copy, or to the retained field content if Copy is disabled. Keep the retained focus target out of the normal Tab sequence. Tab from it reaches the next external control. Leave external focus alone. Use the library's keyboard focus tokens.

Keep the existing value part and plain rendering. Apply trimmed, last-colon, four-code-point grouping to an opted-in whitespace-free identifier. Preserve the prefix and last short group, and use isolated left-to-right identifier content within the surrounding direction. Break between units and within the prefix only when it cannot fit. In compact mode expose the complete identifier separately to assistive technology. Native compact selection includes only the visible prefix and end groups with its ellipsis. Grouped and revealed selection gives the full trimmed string. Exclude accessible-only text from compact selection. The named Copy action always sends the raw value. Bind identifier fragments as text in both presentations.
