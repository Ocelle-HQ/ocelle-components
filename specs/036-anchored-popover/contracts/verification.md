## Interaction and geometry cases

- Use trusted Tab with a following external button deliberately covered by the open panel. Before moving focus, verify that the panel intercepts the external control’s hit point. After moving focus, verify the panel closes without changing the externally focused element, its focus outline is visible and a browser hit reaches it. Keep an unobscured reverse-Tab case and the two foreground overlay sequences.
- Use trusted Escape from both a populated editable native search and a populated readonly search. The editable case clears the value with field focus and the open panel preserved. Its second Escape closes and focuses the trigger. The readonly case closes and focuses the trigger on its first Escape, with the value unchanged. Use the same engine’s independent native input as the clearing oracle if behavior differs across engines.
- Measure the actual native trigger’s inline and block dimensions against resolved `--ocelle-target-min`, its light/dark text, ground, boundary and focus tokens against the checked contrast pairs, and the visible focus ring in both themes and forced colors. Check the panel’s sheet pairs and visible native focus for the real story actions.
- Include top-right and bottom-left clipping fixtures in the real 320 CSS pixel viewport. Verify the correct side and a trusted hit beyond the transformed ancestor’s clip. With tall content and usable space on the preferred side, reject an opposite-side flip even if more space exists there. Cover adjacent and bounded fallback behavior at their thresholds. Prove inner scroll reaches the last control without widening or scrolling the page. Test a same-size moved anchor, viewport resizing, disconnection and responsive hide/show of a still-connected trigger. Confirm it stays closed until fresh activation.
- Separately keep viewport dimensions fixed and double the root text size in the built fixture. Measure the native control’s baseline and enlarged computed font sizes and require a 2:1 ratio. Use a deliberately long action label and verify multiple line boxes, visible focus, unchanged document width and access to the last action.
- Use native touchscreen tap in the dedicated touch file and assert the real outside target activates exactly once with the same focus behavior as an equivalent standalone native control on that browser. Check mouse behavior separately. Keep regular in-process mutation tests for pointer boundaries and geometry.
- Open the panel, press a real primary pointer on an external fixture button that takes explicit capture, drag to a reachable point on a projected panel control and release. Assert the dispatched `pointerup` target is the outside capture owner and the viewport hit at those same coordinates is in the surface. Verify the panel stays open. Pair it with a normal outside activation that closes and preserves the outside target’s activation and focus.

Run the same packaged fixture in Chromium **135.0.7049.114** using the official Linux x64 Chrome for Testing headless shell with the pinned repository Playwright launcher. Run WebKit **17.4** revision **1992** with the matching Playwright **1.43.1** client staged in a disposable Jammy Linux x64 runner at `mcr.microsoft.com/playwright@sha256:1df0e51224b46d872a4185e6c8d6f4b40c22eada49316bb3fd2ade18d0af9536`. Keep the older client outside the project lockfile.

The host entry opens the existing package fixture server with its packaged assets, prints the complete fixture URL and keeps the loopback listener alive until both checks finish. Use Linux host networking for the WebKit process and run the listener in the Docker host’s network namespace, or start the same listener and runner in one disposable namespace. Keep the listener bound to `127.0.0.1` and limit its file scope to the test fixture assets. The runner preflights the exact fixture URL from its own namespace before any interactions. Require an HTTP 200 for the exact route and the package’s full strict CSP header, including the same-origin font directive. Record preflight failures separately from browser behavior failures.

With `fixture_url` from the running host entry and an absolute `compat_stage` containing the exact runner and its isolated `playwright@1.43.1` install, use this invocation on a Linux x64 Docker host.

  node /compat/anchored-popover-compat.mjs webkit "$fixture_url"
