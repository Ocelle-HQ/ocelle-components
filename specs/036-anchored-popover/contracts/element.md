# Public element contract

- Root and `@ocelle/elements/ocelle-anchored-popover.js` import paths. The per-element path registers this element. The exported class is `OcelleAnchoredPopover`.
- `label` names the native button. An absent or whitespace-only label leaves the trigger disabled. The `trigger` slot accepts a decorative icon or initials; the default slot accepts the surface’s ordinary controls. Trigger slot content is noninteractive and the accessible name comes from `label`.
- `placement` selects a preferred `below` or `above` position. It defaults to `below`. After subtracting the anchor gap and viewport gutter, vertical space is usable when the panel can show at least one `--ocelle-target-min` block extent plus its own block padding and borders. Cap the surface to that side’s available extent and scroll excess content inside it. Evaluate the threshold on available space, independently of the current panel size.
- For `below` (top bar), use usable space below first, then usable space above, then a fitting adjacent side. For `above` (bottom rail), use usable space above first, then a fitting adjacent side, then usable space below only if neither promised rail position is possible. An adjacent side fits if its available inline space can contain the viewport-bounded preferred panel inline size and its available block space can meet the same usable threshold. Prefer the logical inline-end side when both fit. If none fits but the visible viewport can hold the minimum extent, clamp the scrollable surface to the visible viewport, with anchor overlap limited to this fallback. If the viewport itself cannot expose an operable target, close without moving focus. Align vertical placements to logical inline start and clamp both axes.
- `close()` closes an open panel and safely does nothing while closed or before first render. If an active node is in its flat surface, return focus to the enabled trigger with no page scroll. If focus has already moved elsewhere, preserve it. No new custom public events, focus trap or forced menu or dialog role.
- `trigger` and `surface` are CSS parts. The native trigger has `--ocelle-target-min` minimum inline and block size and uses `--ocelle-color-focus`, `--ocelle-focus-width` and `--ocelle-focus-offset` for visible focus. On the two supported chrome grounds, use the checked `color-chrome-ink` on `color-chrome`, `color-chrome-hover` and `color-chrome-active` text pairs. Use `color-chrome-muted` against the checked chrome and hover grounds for the resting boundary, and `color-chrome-ink` against the active fill. Keep the focus ring separate from the active fill, over the adjacent chrome ground. Use the panel’s checked `color-ink`, `color-control-border` and `color-focus` on `color-sheet`. Retain meaningful system colors for borders, text and focus in forced colors. No new tokens are required. [Contrast registry](../../../packages/tokens/contrast/pairs.json)

## Interaction and lifetime

The native button toggles its manual popover. Expose expansion on the actual button, and a same-root controls relationship. Native Tab and Shift+Tab follow the shadow invoker and projected contents in document order. Disabled controls stay out. The panel receives no default focus on open. If a native Tab or Shift+Tab initiated at the trigger or in the panel moves focus outside the component, close the panel without transferring that external focus. Let the browser perform the navigation first. This keeps the focused stop visible when the panel had covered its location. Do not close when navigation stays inside or while a foreground overlay owns focus.

Handle Escape on the trigger or within this open surface. Respect an already handled event, composition, and an active foreground close watcher. Keep the existing Ocelle overlay exception for Escape from a populated native search field. The browser can clear the field with its focus and the panel preserved. From the emptied search field, the next Escape closes and restores the trigger. If a focused action opened an externally mounted overlay, its events and focus stay with that overlay until it closes. If a nested surface handles Escape, allow its own handler or native close request to run. Consume the popover’s own Escape so a surrounding Ocelle overlay cannot close on the same key.

For primary outside pointer dismissal, require a matching down/up pair outside both trigger and surface. Use composed paths and the containing root when retargeting hides the inner path. Resolve ambiguous retargeted events after dispatch before dismissing. Cancelled and inside-to-outside drags stay open. Closing cannot prevent or replace the outside target’s pointer activation or move focus back to the trigger. Keep pointer tracking attached only while open. When a rendered trigger becomes disconnected or loses its rendered box, close without transferring focus, clear tracking, pending work and geometry, and update the disclosure state. Restoring visibility does not reopen the panel. Flat containment follows slot assignment and shadow hosts.
