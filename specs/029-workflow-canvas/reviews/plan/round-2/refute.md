## Independent checks

Pinned Chromium 156.0.8078.4 reproduced all three cases. The first button had a right edge of −254.48 CSS pixels and appeared in the accessibility tree as focusable until its wrapper became inert. In the second case, preventing scroll left the pane at zero and native focus on the hidden action. Focusing the same action without preventing scroll moved the pane to 131 CSS pixels. In the third case, pointer capture stayed active and the SVG height held at 100 CSS pixels as its screen Y moved from 88 to 48. The enclosing shadow root received one scroll event. Window, document and the canvas's own shadow root received zero.
