# Public element contract

Import `@ocelle/elements/ocelle-form-textarea.js` to register `ocelle-form-textarea`. The field supports the existing form-control properties and attributes for name, label, description, error, required and disabled, plus `readOnly` / `readonly`. The `value` attribute sets the default. The `value` property gets or sets the current answer. Name, required, readonly and disabled property writes affect participation immediately. A named field is included before first render. The value property and script-visible FormData use LF line breaks, as in a native textarea. Normal URL-encoded submission applies native CRLF serialization. Form association, validity and the label and control parts otherwise follow the library's form-control convention.

A user edit delivers a bubbling, composed native `input` notification after the current and form values are synchronized. A user-committed change delivers `ocelle-form-textarea-change`, bubbling and composed, with `detail: { value: string }`. Enter inserts a newline without implicit submission.
