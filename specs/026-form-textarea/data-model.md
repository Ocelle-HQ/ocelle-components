# Textarea state

- The value attribute carries the default. The non-reflected value property carries the current string. While pristine, a default change updates the current value. User edits and property writes make it dirty. Reset restores the latest default and clears dirty state. Browser form-state restoration restores the current value without a user event.
- Convert CRLF pairs and lone CR to LF at the default, property write and browser restoration boundaries. Reset reuses the normalized default. Native edits arrive normalized. Keep the resulting string in the current value, shadow textarea, form value and stored browser state. Native URL-encoded submission serializes line breaks as CRLF.
- Name, required, readonly and disabled properties reflect synchronously. Recompute ElementInternals validity from current value and effective constraints on changes, including reset and fieldset changes. Native read-only state excludes validation while preserving inclusion and focus. Disabled state, including an ancestor disabled fieldset, removes form participation and tab focus. The library's label, description and host error properties retain their independent roles.
- Keep committed and current value separate. Typing produces input events. A user commit that changes the value emits one component-specific change event. Script writes, reset and restore remain silent.
