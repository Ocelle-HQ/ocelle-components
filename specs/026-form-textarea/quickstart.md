# Verify the textarea

1. Open the editable, invalid, read-only and disabled Storybook stories in both themes. In forced colours, compare the read-only border, focus ring and disabled treatment.
2. In the editable dialog fixture, type a paragraph, press Enter, and paste a second paragraph. Submit, display the host error and check the polite announcement while focus is still on Submit, then edit the answer and resubmit. Confirm the answer retains its line breaks and survives the error. Reset the form and confirm the default is restored.
3. Exercise the focused phase tests through the updated Spec Kit proof and inspect the named assertions. Run the strict-CSP fixture and required merge checks on the final revision. Compare phase proof and CI timing with the pilot targets.
