# Verify the textarea

1. Open the editable, invalid and read-only Storybook stories in both themes.
2. In the editable dialog fixture, type a paragraph, press Enter, and paste a second paragraph. Submit, display the host error, edit the answer and resubmit. Confirm the answer retains its line breaks and survives the error. Reset the form and confirm the default is restored.
3. Exercise the focused phase tests through the updated Spec Kit proof and inspect the named assertions. Run the strict-CSP fixture and required merge checks on the final revision. Compare phase proof and CI timing with the pilot targets.
