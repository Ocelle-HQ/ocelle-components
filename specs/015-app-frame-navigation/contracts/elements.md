# Public element contracts — app frame and navigation

All names below are proposed for plan review. String properties use the corresponding kebab-case attribute. Boolean attributes use presence. Consumers load any primitive through its individual module or the existing package entry.

| Element | Inputs | Slots | Parts |
| --- | --- | --- | --- |
| `ocelle-app-shell` | `layout`, `productName`, `menuLabel`, `drawerLabel`, `closeLabel`, `railLabel`, `sidebarLabel`, `narrowBelow`, `collapseBelow`, `flushBlockEnd`, `flushInlineEnd` | `skip-link`, `actions`, `rail`, `sidebar`, default main content | `main`, `navigation` where navigation is present |
| `ocelle-top-bar` | `productName`, `showMenu`, `menuLabel`, `menuExpanded` | `actions` | `bar`, `brand`, `actions`, `menu-button` |
| `ocelle-nav-item` | `href`, `label`, `current`, `compact` | `icon` | `link`, `label`, `bubble` |
| `ocelle-nav-pill` | `label`, property-only `items` | — | `list`, `link` |
| `ocelle-breadcrumbs` | `label`, property-only `items` | — | `list`, `item`, `link`, `current` |
| `ocelle-skip-link` | property-only `target`, `targetSelector` | Default localized label | `control` |

- Shell tokens `--ocelle-app-shell-narrow-below` and `--ocelle-app-shell-collapse-below` default to 45rem and 68.75rem. The explicit settings take priority when valid. `remeasure()` rereads bounds after a style-only change that does not change the observed box. Tier is observable via read-only `tier`. A bubbling composed `ocelle-app-shell-tier-change` carries `{ tier, previousTier }` after a change and after navigation is presented in the new tier. Initial measurement reports no transition.
- The top-bar menu uses one native button, a localized name, and `aria-expanded`. The button's minimum inline and block sizes use `--ocelle-target-min`, including with long name text and supplied actions. It dispatches one bubbling composed `ocelle-top-bar-menu-request` with `{ expanded: boolean }` giving the requested next state. The standalone host reflects the state back through `menuExpanded`. The shell consumes its own nested top-bar request.
- Shell consumers supply the appropriate sidebar for the layout and an optional mission rail. Supported sidebar content is bare destinations and light-DOM sections or lists, or `ocelle-context-sidebar` with such content in its default slot. For a mission or project sidebar, the shell's tier takes precedence over a descendant nav item's standalone `compact` setting while the item is inside this content. The separate effective presentation applies through nested sections. Keep the host setting intact so it resumes when the item leaves shell-managed content. The expanded and drawer presentations restore labels on the same link; the rail and personal sidebar keep their own presentation. Compact sidebar chrome hides the sidebar head and footer, section headings and separators, and tightens section padding while keeping grouped destinations visible and in order. A keyboard-operable destination belongs in the content region so the drawer can expose it in every supported layout.
- Each region projected as `ocelle-personal-rail`, `ocelle-context-sidebar` or another already named navigation landmark retains its landmark and localized name. Its shell wrapper is neutral. For a bare destination list, the shell wrapper owns the single landmark and uses the supplied `railLabel` or `sidebarLabel`. Hosts provide distinct localized names for different regions, with localized shell defaults for bare lists. Empty or omitted regions expose no navigation landmark. The drawer has its own dialog name and retains these same navigation naming rules. Validate the actual accessibility tree in wide and narrow layouts, with both landed components and bare lists.
- The standalone vertical nav item accepts `current="page"` or `current="true"`. Other values omit current state. Activation follows the native link, without a duplicate custom activation event. A missing destination renders its label without a focusable link. Icon content is decorative when the nav item already has a label.
- The nav pill accepts a readonly ordered array of `{ label: string; href: string; current?: boolean }`. Give its navigation landmark a localizable name through `label`. Render one native link for each destination in array order and mark the first item with `current: true` as `aria-current="page"`. No current item is required. When the list is empty, expose no navigation landmark. Use ordinary link activation and the natural sequential tab order, with no group-selection event, standalone drawer or CTA slot. Use shell navigation for the modal and top-bar actions for a separate CTA.
- Breadcrumbs take a readonly ordered array of `{ label: string; href?: string }`. The final item is current text, even if a URL is supplied. Ancestors with URLs are links. An empty trail exposes no navigation landmark. Separators are decorative and the landmark has a localizable name.
- The skip control has a localized fallback label. The explicit reference wins over `target-selector`. The selector searches its current root and uses the first match. A failed focus attempt leaves the control focused. The shell supports targeting its main through a public `contentTarget` reference after render, keeping IDs local to their own roots.
